# 使用教程

## 第一步：加入 QQ 群

[点击加入 QQ 群](https://qun.qq.com/universal-share/share?ac=1&authKey=...)

群号：**1104148645**

## 第二步：唤醒 ATRI

在群里 @ATRI 或发送唤醒词，她会回应你。

## 第三步：查看帮助

发送「帮助」或「/help」，ATRI 会列出所有可用指令。

## 第四步：开始互动

- **聊天**：直接和她说话，她会根据上下文回复
- **养成**：每天互动会积累好感度
- **点歌**：发送点歌指令，让她用亚托莉声线翻唱
- **语音**：发送语音指令，听她亲口说话

## 常用指令

| 指令 | 说明 |
| :--- | :--- |
| 帮助 | 查看所有指令 |
| 好感度 | 查看当前好感度 |
| 点歌 | RVC 翻唱点歌 |
| 语音 | 触发 TTS 语音 |
| 记忆 | 查看/管理长期记忆 |

> 具体指令以群内实际为准，不同版本可能略有差异。
