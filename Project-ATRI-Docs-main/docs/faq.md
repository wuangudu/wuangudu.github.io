# 常见问题

## 怎么和 ATRI 聊天？

加入 QQ 群后，直接 @她 或使用指令即可。具体指令可以在群里发送「帮助」查看。

## 养成系统怎么提升好感度？

通过日常聊天、互动、赠送礼物等方式提升。好感度越高，解锁的对话和事件越多。

## 长期记忆会记住什么？

ATRI 会记住你们的对话内容、偏好、约定和称呼。她不会记住敏感信息，你也可以随时让她「忘记」某些内容。

## RVC 翻唱怎么点歌？

在群里发送点歌指令，格式参考群内帮助。目前支持的歌曲列表会不定期更新。

## TTS 语音怎么触发？

发送语音指令，或在使用特定功能时自动触发。语音使用亚托莉的声线。

## 机器人不在线怎么办？

可能是维护中或重启。可以稍等几分钟再试，或在群里询问管理员。
