# 功能介绍

ATRI 是一只基于 NapCat 构建的 QQ 机器人，以《ATRI -My Dear Moments-》中的亚托莉为原型。下面是她目前支持的核心功能。

## 🎀 亚托莉养成系统

通过日常聊天、互动、赠送礼物等方式，可以提升与亚托莉的好感度。随着好感度提升，会解锁：

- 专属对话与称呼
- 隐藏剧情与事件
- 特殊互动反馈
- 更多可触发的语音

她不只是机器人，更像是一位会陪你慢慢熟悉起来的伙伴。

## 🧠 长期记忆能力

ATRI 拥有长期记忆系统，能够记住你们之间的：

- 日常对话内容
- 重要约定与偏好
- 人际关系与称呼
- 长期互动历史

这意味着她会记得你上次说过的话，会主动提起之前的话题，也会随着时间推移越来越"懂你"。

## 🎤 RVC 翻唱

基于 RVC（Retrieval-based Voice Conversion）声音模型，ATRI 可以用亚托莉的声线翻唱歌曲。

- 支持点歌翻唱
- 使用亚托莉音色
- 可自定义歌曲列表

想听亚托莉唱你喜欢的歌？在群里直接点歌就行。

## 🔊 TTS 语音服务

ATRI 支持文本转语音（TTS），可以：

- 把文字消息转成语音发送
- 用亚托莉的声音"开口说话"
- 配合翻唱、剧情等功能使用

让聊天不再只是冷冰冰的文字，而是真正能"听见"她的声音。
